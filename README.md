# Forever News

In-game patch notes, hotfixes and announcements for **WoW Forever** (Blizzard Classic+): class filter, search, short summaries.

- Download: CurseForge, project "Forever News" (ID 1788357)
- `ForeverNews/` is exactly what ships to players (addon files only)
- `tools/` is everything around it (fetching the notes, packaging, uploading); it never ships

Patch notes come from Blizzard's official forum posts and news articles. The short summaries are written by an AI; the original text is what counts.
